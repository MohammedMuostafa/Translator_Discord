## ✨ What does it do?

Translator Discord lets you translate messages without leaving Discord.

It can:

* 🌍 Automatically detect the original language
* 🇪🇬 Translate to **Egyptian Arabic**
* 📖 Translate to **Modern Standard Arabic**
* 🇮🇷 Support Persian / Farsi
* 🤖 Use AI for natural translations
* ↔️ Handle Arabic + English mixed text
* 📝 Preserve lists, headings, links, and message formatting
* 🎤 Translate voice/audio when enabled
* 🔊 Read translated text using **Listen**

---

## 🚀 How to use it

First, install the app:

### 👉 [Add Translator Discord to your account](https://discord.com/oauth2/authorize?client_id=1540313821833330739)

After installing it, you can use it in Discord.

### Translate a message

Right-click any message:

```text
Right Click
→ Apps
→ Translate
→ Choose your target language
```

The app automatically detects the source language.

---

### Translate your own text

Use:

```text
/translate
```

Enter your text and choose the language you want.

Example:

```text
Text:
انا داخل الجيم دلوقتي استنوني

Target:
English
```

The app detects that the message is Arabic and translates it automatically.

---

### Write in your language and send in another

Use:

```text
/say
```

Example:

```text
انا داخل بعد خمس دقايق
```

Translate it to English, copy the result, and send it from your own Discord account.

---

## 🔊 Listen to translations

Translated messages may include:

```text
🔊 Listen / استمع
```

Press it to hear the translated text.

---

## ⚙️ Commands

| Command            | What it does                                      |
| ------------------ | ------------------------------------------------- |
| `Apps → Translate` | Translate an existing Discord message             |
| `/translate`       | Translate text                                    |
| `/say`             | Create a translation you can copy and send        |
| `/voice`           | Translate audio                                   |
| `/settings`        | Set your preferred language and translation style |
| `/status`          | Check translator status                           |
