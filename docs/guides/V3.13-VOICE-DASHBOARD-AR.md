# TD AI v3.13 — Voice Reliability + Clean User Dashboard

## أهم تغيير في الـVoice

المشكلة في v3.12 كانت إن Wake Mode كان بيحوّل Conversation Mode من Gemini Live إلى Cascade:

```text
Discord Audio
→ STT
→ Text AI
→ TTS
→ Discord
```

وده معناه إن أي مشكلة في STT أو TTS تخلي البوت ساكت.

في v3.13:

```text
Discord Audio
→ lightweight STT wake gate
→ Gemini Live
→ Discord Audio
```

يعني:
- Gemini Live رجع هو محرك الرد الصوتي الأساسي.
- STT يستخدم فقط لمعرفة هل حد قال TD وهل الكلام موجه للبوت.
- الرد نفسه يخرج من Gemini Live مباشرة، وليس من TTS منفصل.
- لو الشخص قال Wake Word فقط، Gemini Live يقول acknowledgement قصير.
- بعد الرد، Follow-up Window يبدأ من جديد.
- الكلام العادي أثناء Sleeping لا يتم إرساله إلى Gemini Live.
- الكلام العادي أثناء Sleeping لا يخصم User Credits في النظام الداخلي.

Wake aliases أصبحت تشمل:
- TD
- TD AI
- Hey TD
- يا TD
- تي دي
- تيدي
- يا تي دي
- Translator

## Host actions

Wake Mode يدعم:
- `TD اكتب في الشات ...`
- `TD write in the chat ...`
- `TD skip`
- `TD reconnect`
- `TD فاضلي كام`
- Follow-up بدون Wake Word خلال النافذة المحددة.

الأوامر host-side لا تعتمد على أن الموديل "يتخيل" إنه نفذ الأمر.

# Dashboard الجديدة

## User Dashboard

المستخدم العادي لا يرى:
- AI Routing
- Model IDs
- Providers
- API Keys
- Thinking system controls
- Admin users
- Provider health

المستخدم يرى فقط:

### Home
- Current Plan
- Credits remaining
- Monthly usage
- Voice AI information
- Live Translation information

### Plans
- Free
- Plus
- Pro
- Credits
- Voice availability
- Live Translation availability

الدفع غير مربوط لسه، فالـUpgrade يظهر Coming Soon.

### Personalize

#### Text
Discord لا يسمح للبوت يفرض Font Family حقيقي.

المستخدم يقدر يغير:
- Heading Size
- Spacing / Density
- Emojis
- Original preview

التغيير يطبق على ردود Discord التي تمر من `editOriginalResponse`.

#### Voice
المستخدم يقدر يختار Voice من قائمة آمنة مثل:
- Kore
- Puck
- Charon
- Aoede
- Fenrir
- Leda
- Achird
- Sulafat
- Gacrux
- Vindemiatrix

ويقدر يحدد Response Delay:
- Instant
- 0.25 sec
- 0.5 sec
- 1 sec
- 1.5 sec
- 2 sec
- 3 sec

Voice + Delay يطبقوا على الـVoice Session الجديدة بعد Leave / Join.

# TTS Fix Included

النسخة تحتوي أيضًا على إصلاح Gemini TTS streaming من v3.12.2:
- SSE streaming
- inline audio
- real error event handling
- diagnostics بدل `returned no audio chunks` المبهمة

ده مهم للـListen ولـLive Translation Voice Output، حتى لو Conversation Mode نفسه بقى يعتمد على Gemini Live للصوت.
