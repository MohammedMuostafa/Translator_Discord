# TD AI v3.14 — Media Studio + Plan Model Tiers + Dashboard Redesign

## أهم الجديد

### 1) Model tiers حسب الخطة

TD AI بقى يمنع تسريب موديل أعلى لخطة أقل.

لو الـAdmin route مثلًا:

```text
gemini-3.7-flash | gemini-3.6-flash | gemini-3.5-flash-lite
```

النظام يعمل فلترة حسب خطة المستخدم:

- Free: يأخذ فقط الموديلات المسموحة لـ Free
- Plus: يصل إلى 3.6 class
- Pro: يصل إلى 3.7 / Pro class

المستخدم لا يرى Model IDs ولا يختار Provider.

---

## Text tiers

### Free
- Gemini 2.5 Flash Lite
- Gemini 3.1 Flash Lite
- Gemini 3.5 Flash Lite
- Gemini 2.5 Flash

### Plus
كل Free بالإضافة إلى:
- Gemini 3 Flash
- Gemini 3.5 Flash
- Gemini 3.6 Flash

### Pro
كل Plus بالإضافة إلى:
- Gemini 2.5 Pro
- Gemini 3.1 Pro
- Gemini 3.7 Flash

ملحوظة:
- IDs الخاصة بـ 3.6 / 3.7 مأخوذة من AI Studio quota view اللي عندك.
- الموديلات الجديدة غير المعروفة في Catalog تعتبر Pro-only افتراضيًا حتى لا تتسرب لخطة أقل.

# 2) Image Studio

تم إضافة Discord commands:

```text
/image generate
/image edit
```

المستخدم يختار فقط:

- Prompt
- Quality:
  - Draft
  - Standard
  - Premium
- Aspect ratio

هو لا يختار Nano Banana model.

### Image plan routing

Free:
- Nano Banana 2 Lite
- 20 generations / month
- 30 edits / month

Plus:
- Nano Banana 2 Lite / Nano Banana 2
- 200 generations / month
- 300 edits / month

Pro:
- Nano Banana 2 / Nano Banana Pro
- 1000 generations / month
- 1500 edits / month

API model IDs المستخدمة:

```text
gemini-3.1-flash-lite-image
gemini-3.1-flash-image
gemini-3-pro-image
```

# 4) Credits + Media job limits

Media عندها حدين:

1. Unified TD Credits
2. عدد Jobs شهري

يعني حتى لو المستخدم عنده Credits، لو وصل لعدد الفيديوهات الشهري يتم منعه.

Default product credit costs:

Image generate:
- Draft: 800
- Standard: 1600
- Premium: 3000

Image edit:
- Draft: 600
- Standard: 1200
- Premium: 2500

Video:
- Lite: 8000
- Fast: 15000
- Cinematic: 30000

دي Product Credits وليست Google API tokens أو السعر المالي الفعلي.

# 5) Dashboard الجديدة

## User View

المستخدم العادي يرى فقط:

```text
Home
Create
Plans
Personalize
```

لا يرى:
- AI Routing
- Provider names
- API Keys
- Model IDs
- Provider Health
- System Thinking settings

### Home
- Plan
- Credits
- Usage
- Features
- Image quota
- Video quota
- Live Translation access

### Create
واجهة Creative Studio تساعده يبني:

```text
/image generate
/image edit
/video generate
```

ويختار Quality فقط وليس Model.

### Plans
واجهة Plans جديدة تعرض:
- Credits
- Voice
- Live Translation
- Image generations
- Image edits
- Videos
- AI quality tier

### Personalize
- Heading size
- Spacing
- Emojis
- Original preview
- Voice
- Response delay

---

## Admin View

الـAdmin يدخل User View طبيعي.

يظهر له زر:

```text
Admin Console
```

ويفتح:

```text
/admin?view=admin
```

Admin فقط يرى:

```text
Overview
Users & Plans
Model Catalog
AI Routing
Providers & APIs
Voice System
Provider Health
```

الـAdmin HTML لا يتم إرساله أصلًا للمستخدم العادي.
