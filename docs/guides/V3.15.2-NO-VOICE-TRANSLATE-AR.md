# TD AI v3.15.2 — Remove Voice Translate

تم إلغاء Voice Translation mode فقط.

## الموجود بعد التحديث

يبقى شغال:

```text
/voicechat join
/voicechat write
/voicechat skip
/voicechat reconnect
/voicechat usage
/voicechat status
/voicechat leave
```

ويتم حذف:

```text
/voicechat translate
/voicechat translate-stop
```

## مهم

- Text translation `/translate` لم يتم لمسها.
- Voice upload/transcription `/voice` لم يتم لمسها.
- Normal Voice Chat يعتمد على `/voicechat join` وGemini Live.
- الـAdmin Dashboard لن يعرض Live Voice Translation أو `voice_translate`.
- لو كان فيه Session قديمة Translation وعملت reconnect، سترجع Conversation عادي.
- تم تضمين إصلاح TypeScript Buffer الذي كان يسقط Railway عند `voiceAi.ts(1766,9)`.

## Commit

```text
Remove live voice translation and keep normal voice chat
```

