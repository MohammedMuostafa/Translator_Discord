# TD AI v3.15 — Stability / Managed Routing / Native Live Translate / Media Fixes

هذا التحديث يجمع إصلاحات المشاكل الحالية في Patch واحد مرتب على نفس مسارات GitHub.

## 1) Voice Chat العادي

Conversation Mode يظل **Always Listening** كما طلبنا:

```text
Discord voice
→ Gemini Live
→ spoken response
```

لا يوجد Wake Word ولا Follow-up Window.

### Managed Live Voice fallback

TD AI يجرب تلقائيًا:

```text
gemini-3.1-flash-live-preview
→ gemini-2.5-flash-native-audio-preview-12-2025
```

الـfallback يعمل عند بداية الـsession، وفي v3.15 يوجد runtime failover أيضًا لو الـLive socket الحالي وقع أثناء الجلسة.

## 2) Live Voice Translation

المسار الأساسي لم يعد:

```text
STT → text translation → TTS
```

بل أصبح:

```text
Discord PCM audio
→ Gemini 3.5 Live Translate
→ translated PCM audio
→ Discord
```

الموديل:

```text
gemini-3.5-live-translate-preview
```

TD يفتح target stream لكل لغة، مع `echoTargetLanguage: false`، لذلك الكلام في اللغة A يخرج في B والعكس بدون انتظار STT turn كامل.

الصوت الداخل يرسل PCM16 mono 16kHz في chunks ~100ms.

لو Native Live Translate وقع، TD يحول تلقائيًا إلى:

```text
STT → text translation → TTS
```

كـfallback فقط.

---

## 3) TTS error fixed

المشكلة القديمة:

```text
Audio delivery mode is not supported.
```

كانت بسبب Interactions payload قديم/غير مناسب:

```text
delivery: inline
mime_type: audio/l16
```

v3.15 يستخدم `generateContent` TTS schema:

```text
responseModalities: AUDIO
speechConfig.voiceConfig.prebuiltVoiceConfig.voiceName
```

Managed fallback:

```text
gemini-3.1-flash-tts-preview
→ gemini-2.5-flash-preview-tts
```

---

## 4) Image generation fixed

المشكلة القديمة:

```text
image/png is not supported for response_format.mime_type
```

تم إزالة إجبار `image/png` بالكامل.

v3.15 يستخدم `models.generateContent` مع:

```text
responseModalities: IMAGE
responseFormat.image.aspectRatio
responseFormat.image.imageSize
```

ويقرأ MIME الحقيقي من `inlineData.mimeType`.

### Image model chains by plan

Free:
```text
gemini-3.1-flash-lite-image
```

Plus Standard:
```text
gemini-3.1-flash-image
→ gemini-2.5-flash-image
→ gemini-3.1-flash-lite-image
```

Pro Premium:
```text
gemini-3-pro-image
→ gemini-3.1-flash-image
→ gemini-2.5-flash-image
```

> مهم: Google Gemini image-generation API ليس له Free API quota في الـDeveloper API. لو مشروع Google نفسه يظهر 0/0 فلا يوجد كود يقدر يتخطى ده؛ لازم Paid Gemini API billing/quota يكون متاح للمفتاح المستخدم في Railway.

TD product credits لا تُخصم إذا فشل provider قبل إنشاء الصورة/الفيديو.
