# TD AI v3.15.1 — TypeScript Buffer Build Fix

Railway error:

```text
TS2322: Type 'Buffer<ArrayBufferLike>' is not assignable to type 'Buffer<ArrayBuffer>'
```

The failing code is inside the Live Translation PCM buffer:

```ts
let pending = Buffer.alloc(0);
...
pending = pending.byteLength
  ? Buffer.concat([pending, pcm])
  : pcm;
```

With TypeScript 7 + @types/node 24, `Buffer.alloc(0)` can infer a narrower
`Buffer<ArrayBuffer>` type while decoded/converted PCM is
`Buffer<ArrayBufferLike>`.

Fix:

```ts
let pending: Buffer<ArrayBufferLike> = Buffer.alloc(0);
```

No runtime behavior changes. This is only a compile-time type fix.
