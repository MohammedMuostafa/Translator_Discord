# TD AI v3.14.1 — Voice Reliability Hotfix

المشكلة الظاهرة:

```text
TD AI Voice: Gemini STT detected no speech.
```

سببها إن Wake Mode في v3.13/v3.14 كان يعتمد على خطوة STT منفصلة قبل ما يسمح للطلب يدخل Gemini Live.

لو Gemini STT لم يلتقط كلمة قصيرة مثل:

```text
TD
تي دي
تيدي
```

الجلسة كانت تتوقف قبل ما Gemini Live يسمع الصوت أصلًا.

## الإصلاح

### 1. Automatic Live fallback

المسار أصبح:

```text
Discord Audio
   ↓
Wake STT
   ├── نجح → Host wake gate → Gemini Live
   └── فشل / no speech → نفس الصوت الخام → Gemini Live مباشرة
```

يعني خطأ STT لم يعد يقتل المحادثة.

### 2. Wake safety on fallback

عند استخدام الـfallback، Gemini Live نفسه يتلقى تعليمات:

- لا يتكلم في الكلام العادي.
- يرد فقط لو سمع TD / TD AI / تي دي / تيدي / يا تي دي.
- الـhost-tagged turns مثل `[TD_ACCEPTED]` تعتبر مصرح بها.

### 3. Better short-phrase STT prompt

تم توضيح لـGemini STT إن الملف قد يحتوي فقط على كلمة قصيرة جدًا مثل `TD`، وإنه لا يرجع نص فارغ لو فيه صوت بشري مسموع.

### 4. Less aggressive end-of-speech

Wake capture يستخدم minimum 650ms silence قبل إغلاق الجملة.

ده يقلل تقطيع:

```text
TD ... اكتب في الشات ...
```

إلى جملتين منفصلتين.
