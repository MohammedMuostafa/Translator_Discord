# TD AI v3.14.5 — Always Listening Voice

تم إلغاء فكرة Wake Word بالكامل في Conversation Voice.

## السلوك الجديد

```text
User speaks
↓
Discord captures the utterance
↓
Gemini Live receives it directly
↓
TD replies
```

لا تحتاج تقول:

```text
TD
تي دي
يا TD
```

ولا يوجد:
- Wake window
- Follow-up window
- Wake STT gate

## Who can talk

الإعداد الوحيد المهم للمجموعة:

```text
Admin → Voice System → Who can talk
```

- `Everyone` = كل البشر في نفس الـVoice Channel يقدروا يكلموا TD.
- `Owner only` = صاحب الـsession فقط.

للاستخدام الجماعي اختار:

```text
Everyone
```

## End-of-speech silence

القيمة المقترحة:

```text
650 ms
```

لو أقل جدًا مثل `250ms` ممكن الجملة تتقطع مع أي pause صغيرة.

## ملاحظات

- Live Translation تظل continuous كالمعتاد.
- أوامر `/voicechat write`, `skip`, `reconnect`, `usage` تظل موجودة.
- Wake-related code قد يظل داخل الملف كـlegacy helper لكنه غير مستخدم في Conversation Mode.
- الإعدادات القديمة المحفوظة كـ`wake-word` يتم تجاهلها، والنظام يجبر Conversation Mode على `always`.
