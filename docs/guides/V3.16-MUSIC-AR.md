# TD AI v3.16 — Discord Music Playback

## الجديد

TD AI يقدر يشغل موسيقى داخل نفس Voice Channel بطريقتين:

### 1) Slash Commands

```text
/music play query:<song name or public link>
/music pause
/music resume
/music skip
/music stop
/music queue
/music now
```

لو كتبت اسم أغنية بدل لينك، TD Music يستخدم `yt-dlp` مع بحث `ytsearch1:` لاختيار أول نتيجة عامة قابلة للتشغيل.

### 2) Voice AI Tool Calling

في Voice AI العادي تقدر تقول مثلًا:

```text
شغللي Tamally Maak Amr Diab
شغل الأغنية دي https://...
Play Blinding Lights
```

Gemini Live لا يتظاهر إنه شغّل الأغنية. بدل ذلك يستدعي Host Tool اسمه `play_music`، والـhost runtime هو اللي يبدأ التشغيل فعلًا.

Live tools الموجودة:

```text
play_music
pause_music
resume_music
skip_music
stop_music
```

## أثناء تشغيل الموسيقى

TD يمنع المحادثة الصوتية العادية من استبدال Audio Resource الخاص بالأغنية. بدل ذلك، الكلام البشري يتم فحصه كـmusic-control command باستخدام STT فقط.

أمثلة تحكم صوتي أثناء الأغنية:

```text
وقف الأغنية
وقف مؤقت
كمل الأغنية
اللي بعدها
شغللي أغنية ثانية
```

الكلام العادي أثناء الأغنية يتم تجاهله بدل ما يقطع الأغنية أو يخلي AI يتكلم فوقها.

## Queue

`/music play` أثناء وجود Track شغال يضيف الأغنية للـqueue.

أما أمر صوتي مثل:

```text
شغللي أغنية ثانية
```

فهو يستبدل الأغنية الحالية ويبدأ الجديدة مباشرة.

## Runtime Dependencies

Dockerfile أصبح يثبت:

```text
ffmpeg
yt-dlp
```

عن طريق Alpine `apk`.

لا توجد npm dependencies جديدة.

## الروابط المدعومة

الـbackend يعتمد على `yt-dlp`، لذلك يدعم الروابط العامة التي يستطيع `yt-dlp` حلها. البحث بالاسم يستخدم YouTube search.

Spotify links ليست Audio Stream مباشر عادة؛ يمكن إضافة Spotify metadata resolver لاحقًا ثم البحث عن نفس الأغنية في مصدر قابل للتشغيل.

TD AI لا يحاول تجاوز DRM أو paywalls.

## YouTube Datacenter Restrictions

بعض Cloud IPs قد يتلقوا YouTube bot checks أو PO-token/cookie requirements. لو حصل ذلك، TD Music يعرض Error مختصر بدل raw process output.

## Build Fix Included

الملف `src/services/voiceAi.ts` في هذا التحديث مبني فوق v3.15.2 الحالية، لذلك يحتفظ بإصلاح Buffer typing الذي كان مطلوبًا لخطأ Railway السابق.
