Translator Discord — Privacy Policy

Last updated: August 21, 2026

This Privacy Policy explains how Translator Discord ("Translator Discord", "the App", "we", "our", or "us") processes information when you use the application.

Important: Translator Discord only processes content when a user intentionally invokes one of its commands or translation interactions. The App is not designed to continuously monitor Discord conversations.

1. Information We Process

Depending on the feature being used, Translator Discord may process the following information:

  • Text that you intentionally submit for translation.
  • The content of a Discord message that you explicitly select using a Translator Discord message command.
  • Audio or voice files that you intentionally submit for speech-to-text or translation.
  • Your Discord user ID when required to associate application preferences with your account.
  • Translation preferences such as preferred language, target language, translation style, or provider.
  • Technical information required to process a Discord interaction.

2. Information We Do Not Request

Translator Discord does not require your Discord password and does not require access to your personal Discord user token.

You should never provide your Discord password, Discord user token, API keys, authentication secrets, or other private credentials through a translation command.

3. How Information Is Used

Information processed by Translator Discord is used to:

  • Translate text between supported languages.
  • Detect the source language of submitted text.
  • Distinguish between supported language variants where possible, including Egyptian Arabic and Modern Standard Arabic.
  • Apply translation styles such as natural, casual, formal, or literal translation.
  • Convert submitted voice or audio into text when speech recognition features are used.
  • Remember user-selected language preferences where this feature is enabled.
  • Diagnose errors, prevent abuse, and maintain the reliability and security of the App.

4. AI Translation

Translator Discord may use artificial intelligence services to perform translation, language detection, dialect recognition, and style-aware translation.

The current deployment may use Google Gemini API for AI-assisted translation.

When Gemini is selected or configured as the translation provider, the text required to complete your translation request may be transmitted to Google's Gemini API for processing.

Google processes data submitted to its services according to its own applicable terms, policies, and API settings.

5. LibreTranslate

Translator Discord may also use LibreTranslate as a translation provider or fallback translation service.

When LibreTranslate is used, the text required for the translation request is transmitted to the configured LibreTranslate service.

In deployments where LibreTranslate is self-hosted, the service may run within the same private hosting infrastructure as Translator Discord.

6. Voice and Speech-to-Text

If voice translation features are enabled, audio intentionally submitted by a user may be processed by a speech-to-text service before translation.

Audio is processed only when the user explicitly invokes a feature that requires audio transcription or translation.

Users should only submit audio they have permission to process.

7. Discord Interaction Data

Translator Discord operates primarily through Discord application interactions such as slash commands and message context commands.

Discord may provide information necessary to process an interaction, such as:

  • Discord user ID
  • Interaction ID
  • Application command information
  • Selected message content
  • Relevant Discord context

Translator Discord does not use a self-bot and does not automate a user's personal Discord account.

8. Data Storage

Translator Discord is designed to minimize permanent storage of translation content.

Translation text is generally processed for the purpose of completing the requested interaction rather than being intentionally retained as a permanent message history by the App.

Limited application preferences may be stored, including settings such as a user's preferred language.

Hosting infrastructure and third-party providers may temporarily process or retain technical logs according to their own operational and privacy practices.

9. API Keys and Secrets

Private API credentials used by the official deployment, including AI provider keys and Discord application secrets, are intended to be stored securely as server-side environment variables.

These secrets are not intended to be included in the public GitHub repository.

Public copies or forks of the Translator Discord source code must use their own credentials and service configuration.

10. Public Source Code

Translator Discord may make its source code publicly available through GitHub.

Public availability of the source code does not provide access to the credentials, API keys, hosting accounts, Discord application secrets, or private infrastructure of the official deployment.

11. Third-Party Services

Translator Discord may rely on third-party services, including:

  • Discord
  • Google Gemini API
  • LibreTranslate
  • Railway or another hosting provider
  • GitHub
  • Speech-to-text providers or software

These services have their own terms and privacy policies. Translator Discord does not control the independent data practices of third-party providers.

12. Data Sharing

We do not sell personal information.

Information may be transmitted to third-party providers only where necessary to operate features such as translation, AI processing, hosting, or speech recognition.

13. Data Security

Reasonable technical measures are used to protect the application and its credentials.

However, no internet-based system can guarantee absolute security.

14. Data Retention

Translator Discord aims to retain only the information reasonably necessary to operate the App.

User preferences may remain stored until they are changed, deleted, or the associated storage is reset.

Temporary operational logs may be retained by hosting or API providers according to their respective policies.

15. User Controls

Users control when Translator Discord processes content by choosing when to invoke the App.

Removing Translator Discord from your Discord account prevents future use of its user-installed commands unless it is installed again.

16. Children's Privacy

Translator Discord is intended to be used consistently with Discord's own age requirements and policies.

The App is not intentionally designed to independently collect personal information from children outside the normal operation of Discord application interactions.

17. Changes to This Privacy Policy

This Privacy Policy may be updated when Translator Discord adds new features, providers, integrations, or data processing practices.

The date at the top of this page will be updated when material changes are made.
